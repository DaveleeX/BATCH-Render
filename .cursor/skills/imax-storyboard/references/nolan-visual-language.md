# 视觉语言：诺兰 / 大画幅

分镜的"质感"不是画风滤镜，是**一整套可复述的物理决定**：什么画幅、什么镜头、什么胶片、光从哪来。这份文档给出这些决定的真实参数与取舍逻辑。

## 1. 画幅与格式

### IMAX 15/70 —— 1.43:1

| 项 | 参数 |
| --- | --- |
| 底片 | 65mm 负片，横向走片，每格 15 齿孔（发行拷贝印在 70mm 上，多出的宽度放声轨） |
| 感光面（camera aperture） | 70.41 mm × 52.63 mm |
| 放映画幅 | 1.43:1（放映窗口比感光面小：纵向至少小 2 mm、横向至少小 0.41 mm） |
| 镜头 | 球面（spherical），无变形宽银幕 |
| 帧率 | 24 fps |
| 数字 IMAX 转制画幅 | 1.90:1 / 2.39:1 |
| 单卷片长 | 约 2 分钟 |
| 机身 | IMAX MSM 9802 / MKIV，含镜头约 50 磅，**运转噪音大**，同期收音困难 |

感光面的数学比例是 1.34:1，但放映窗口裁出的是 1.43:1——**画的时候按 1.43 画，知道上下还有一点余量就行**。

### 与它搭配的次级格式

| 格式 | 画幅 | 在诺兰片里的角色 |
| --- | --- | --- |
| 5-perf 65mm（Panaflex System 65 Studio / Arriflex 765） | 2.20:1 | 同期声对白戏。机身有隔音罩（blimped），IMAX 太吵时用它。单卷约 8 分钟 |
| 35mm 4-perf 变形宽银幕 | 2.39:1 | 早期片（《黑暗骑士》系列）的非 IMAX 部分 |
| 数字 IMAX 发行 | 1.90:1 | 影院端最常见的"宽 IMAX" |

### 画幅切换的纪律

画幅跳变是**叙事信号**，不是炫技。它可以标记：

- 客观 / 主观（《奥本海默》：彩色 = 奥本海默视角，黑白 = 施特劳斯视角的"客观"叙述）
- 现实 / 记忆 / 梦境层级
- 尺度切换：亲密对白 → 天地景观

实拍时的构图纪律是"**主要按 2.40 构图，保护框外的部分**"。结果是：1.43 版本里的近景会有**大量额外头顶空间**——在 IMAX 巨幕上这反而是对的，因为观众的视线本来就在画面中央游走，构图的作用小于沉浸感。

分镜落实办法：画 1.43 的格子，用虚线标出内嵌的 2.39 安全区，主体信息压在安全区内。

## 2. 镜头与景深

### 焦距甜区：50mm 与 80mm

Hoyte van Hoytema 的原话逻辑：**超出这两个焦距，沉浸感就掉**。太长 → 画面被压缩，变得"像在看一块平面图形"；太广 → "鱼缸感"，边缘掉落太快。

- **50mm** = 广角镜（IMAX 上）
- **80mm** = 近景/特写镜

### 换算：IMAX 焦距在直觉上等于多少

以水平视角折算（IMAX 感光面宽 70.41 mm）：

| IMAX 焦距 | ≈ 全画幅（36mm） | ≈ Super35（24.89mm） | 水平视角 |
| --- | --- | --- | --- |
| 30mm | 15mm | 11mm | 99° |
| **50mm** | **26mm** | **18mm** | 70° |
| **80mm** | **41mm** | **28mm** | 47° |
| 110mm | 56mm | 39mm | 35° |
| 250mm | 128mm | 88mm | 16° |

**记忆法：IMAX 焦距 ÷ 2 ≈ 全画幅焦距，÷ 2.8 ≈ S35 焦距。**

这解释了诺兰特写的核心特征：**它是用中焦、贴得极近拍的**，不是用长焦压出来的。所以人脸巨大，同时环境还在，透视是自然的——像人眼凑近看人，而不是像监视器偷窥。

### 景深

大画幅在等效构图下景深更浅。等效光圈 ≈ 实际 T 值 ÷ 裁切系数（IMAX vs 全画幅约 1.96）：

- IMAX 80mm **T2.0** ≈ 全画幅 41mm **f/1.0** 的虚化量。

所以大特写的焦点极薄——**睫毛清楚、耳朵已经化开**。反过来，大远景为了保住纵深细节，会收光圈、靠自然光量硬撑。

分镜要写清楚：这一格是"薄焦点贴脸"还是"深焦纵深"，两者是完全不同的情绪。

### 定制光学

原厂 IMAX 镜头偏暗，Panavision 的 Dan Sasaki 为剧组改造出 **T2.0** 的版本，并改近对焦距离以便贴近拍摄。另有：

- **潜望（snorkel）镜头**：进战斗机座舱、进狭小空间；《奥本海默》还做了防水版
- **micro-macro 50/80mm**：可达 1:1 放大，用于插入镜头（instrument、水滴、粒子）和"史上最大的 IMAX 特写"
- 改造的 Hasselblad 静态摄影镜头、Panavision Sphero 65、System 65

分镜里遇到"钻进仪表盘 / 贴着水面 / 极端微距"的想法时，写上 `snorkel` 或 `micro-macro`——它标明这是可实拍的。

## 3. 胶片与色彩

Kodak 65mm 大画幅负片，三种主力：

| 片种 | 用途 | 画面性格 |
| --- | --- | --- |
| VISION3 250D 5207 | 外景、明亮日内 | 干净、宽容度大、肤色自然 |
| VISION3 500T 5219 | 弱光、夜戏 | 颗粒更明显、阴影通透 |
| EASTMAN DOUBLE-X 5222（65mm 版为《奥本海默》专门制造） | 黑白叙事线 | 高反差、结实的中间灰、颗粒硬 |

写在提示词里的落点：**颗粒、卤化银质感、阴影里保留信息、高光滚降柔和**。不要"HDR"、"超清锐利"、"数字通透"。

黑白线要按**灰阶**思考而不是"去色"：先想这块是几区，再想它长什么样。

## 4. 光

原则：**光必须有来源，并且大多数时候来源在画内或画外可指认**。

常见光源清单（写分镜时直接选）：

- 大面积柔光从窗户进来（日内主力）
- 钨丝灯实用光源（台灯、吊灯、仪表盘、指示灯）在画内
- 火 / 爆炸 / 探照灯：动态、有方向、会晃
- 天空散射：阴天海滩的无影灰光
- 直射硬阳 + 沙尘/水汽 → 可见光束
- 单一实用光源打侧脸，另一侧**不补光**，直接掉进阴影

反面清单：无来源的轮廓光、无理由的彩色边光、均匀无阴影的"商业打光"。

## 5. 美术与质感

- 混凝土、钢、玻璃、粗野主义建筑；对称的大体量
- 真实场景优先于摄影棚；能实景就实景
- 服装与道具**有使用痕迹**：汗、灰、油、磨损
- 天气是角色：风、雨、尘、雾
- 效果尽量实拍：真炸、真旋转布景、真飞机——分镜备注里写清楚实拍方案

## 6. 声音提示（写进分镜格）

分镜格要带声音栏，因为诺兰的镜头长度经常由声音决定：

- 持续升调的紧张感（Shepard tone 式无限上升错觉）
- 低频压迫（次低频推进）
- 机械节拍 / 秒针 / 心跳作为剪辑节拍器
- **突然的绝对静默**——爆炸前的空白比爆炸本身更响
- 对白被环境声压过（诺兰的招牌争议点，但它是设计）

## 7. 各片风格档案

选一个作为基调，比空泛地说"诺兰风格"精确得多。

### 《黑暗骑士》/《盗梦空间》（Wally Pfister 时期）

高反差、冷钢蓝的城市夜，钠灯橙点缀；玻璃幕墙反射；构图工整偏建筑感；IMAX 段落用于城市尺度与动作高潮。

### 《星际穿越》（Hoytema，2014）

自然主义。玉米地的尘、飞船内的实用光、太空的绝对黑与硬光。大量 IMAX 外景。质感朴素得近乎纪录片，靠尺度而不是靠打光取胜。

### 《敦刻尔克》（2017）

灰蓝、沙色、去饱和。阴天海滩的无影光。**大量手持 IMAX**（摄影师亲自扛，器材背包由握把员背着或放在小筏上）。全片 79 分钟为 IMAX 胶片素材。三条时间线（一周 / 一天 / 一小时）交叉。对白极少，画面叙事为主。

### 《信条》（2020）

冷、干、去饱和的混凝土世界。全部球面镜。常用镜是定制 Panavision Sphero 80mm。IMAX 用于动作与需要后期配音的场次；同期声对白戏走 2.20:1。

### 《奥本海默》（2023）

彩色（奥本海默主观）+ IMAX 黑白（施特劳斯线）双轨。钨丝灯暖调室内、听证会小房间的压迫构图、新墨西哥的强日光与尘。**IMAX 大特写贴脸**——为此专门定制近对焦光学，做出"逼视式的偏执特写"。宏观（宇宙、粒子、火）与微距插入镜交替。

## 8. 常见误区

| 错误做法 | 正确做法 |
| --- | --- |
| 加变形宽银幕蓝色横向光斑 | 球面镜，无光斑；要炫光就用真实的太阳/实用光源产生的柔光晕 |
| 用长焦压出"电影感"特写 | 中焦（IMAX 80mm）贴近拍，保留环境与自然透视 |
| 把 1.43 当成"竖屏" | 它是近方形的**大**画幅，上下空间要承载天空、地面、天花板、纵深 |
| 阴影压死成纯黑 | 阴影里保留可读的细节和颗粒 |
| 全片一个画幅还硬说是 IMAX 风格 | 画幅切换要服务叙事分层，或者干脆全片单一画幅并说明理由 |
| 大量升格慢镜 | 24fps 实时，紧张感来自剪辑与声音 |
| 用绿幕思维设计镜头 | 先问"这能怎么实拍" |

## 事实来源

IMAX 15/70 技术规格来自 IMAX 格式公开规格（camera aperture 70.41 × 52.63 mm、1.43:1、球面镜、24fps、DMR 1.90/2.39）。镜头甜区、定制光学、手持方案、胶片片号与黑白 65mm 定制过程，来自 Hoyte van Hoytema 就《敦刻尔克》《信条》《奥本海默》接受的 Kodak、British Cinematographer、Cinematography World、IndieWire 等访谈。
