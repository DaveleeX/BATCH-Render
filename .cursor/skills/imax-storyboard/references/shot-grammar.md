# 镜头语法：在 1.43:1 里怎么构图、运动、剪辑

宽银幕的构图经验在 1.43:1 里大半失效。这份文档处理"近方形大画幅"特有的问题。

## 1. 1.43:1 的构图逻辑

宽银幕靠**横向并置**讲关系（两个人分居左右、地平线拉长）。1.43 横向不够用，它靠**纵向堆叠**和**纵深**讲关系。

### 三条可操作的规则

**规则一：上下空间必须干活。**
多出来的高度要装东西——天空、云、天花板、悬在头顶的结构、脚下延伸的地面。如果上半格是空白墙、下半格是空白地，这个构图就浪费了画幅，改用 2.39 更好。

**规则二：把关系放进纵深，而不是左右。**
两个人对峙，宽银幕分左右；1.43 让一个人在前景（大、虚或实）、一个人在后景（小、实）。前后景的大小差在大画幅上极其明显，这就是权力关系。

**规则三：地平线压低，人就变大；地平线抬高，人就被吞掉。**
1.43 的高度让这个选择的效果被放大数倍。海滩上的士兵、荒原上的房子、爆炸前的观测掩体——地平线位置就是主题陈述。

### 近景在 1.43 里的样子

按 2.39 构图 + 保护上下，意味着 1.43 版本的近景**头顶空间非常大**。不要按照常规"眼睛在上三分线"的教条把脸顶上去。在巨幕上，脸落在画面中央偏下、头顶留出大片环境，才是对的比例感。

### 构图工具箱

- **对称正面**：审讯、听证、仪式、权力场景。中轴线对齐，主体正对镜头
- **单点透视纵深**：走廊、隧道、跑道、桌子长边——把观众吸进画面
- **前景遮挡**：肩、门框、机翼、人群后脑——大画幅下前景虚化极重，产生"偷看"的临场感
- **孤立体与巨大负空间**：沙滩上的一个人、雪原上的一辆车
- **头顶压迫**：低机位仰拍 + 天花板/结构入画，1.43 的高度让压迫感成倍
- **地面延伸**：高机位俯拍 + 地面填满下半格，产生眩晕与规模

## 2. 景别 × 焦距对照

IMAX 画幅上只用 50 / 80 两个焦距，所以"景别"主要靠**机身距离**实现，不是靠变焦。

| 景别 | 缩写 | IMAX 焦距 | 大致距离 | 用途 |
| --- | --- | --- | --- | --- |
| 大远景 | EWS | 50mm | 极远 | 尺度、孤立、地理关系 |
| 远景 | WS | 50mm | 远 | 环境中的人，交代空间 |
| 全景 | FS | 50mm | 中远 | 全身，肢体表演 |
| 中景 | MS | 50 / 80mm | 中 | 腰以上，对话基本单位 |
| 中近景 | MCU | 80mm | 近 | 胸以上，最常用的对白景别 |
| 近景 | CU | 80mm | 很近 | 脸，情绪主力 |
| 大特写 | ECU | 80mm（近对焦改造） | 极近 | 眼、嘴、手——"逼视式偏执特写" |
| 插入镜 | INS | micro-macro 50/80 | 微距 | 仪表、纸面、水滴、粒子 |
| 座舱/狭小空间 | — | snorkel | — | 常规镜头进不去的位置 |

写分镜时，景别和焦距要同时标。只写"特写"不够——80mm 贴近的特写和 250mm 远距的特写是两种完全不同的画面。

## 3. 运镜

大画幅机器重（含镜头约 50 磅），这个物理限制反而定义了风格：**运动少、但每次运动都有重量**。

| 运动 | 写法 | 什么时候用 | 大画幅注意 |
| --- | --- | --- | --- |
| 固定 | STATIC | 默认。让画面自己说话 | 大画幅静止镜头信息量已经很大 |
| 手持 | HANDHELD | 战斗、混乱、贴身跟随 | 真实可行——摄影师扛机，握把员协助支撑；幅度小、有沉重的惯性感，不是轻飘的抖 |
| 推 / 拉 | PUSH IN / PULL OUT | 情绪逼近或抽离 | 慢、稳、匀速 |
| 横移 | DOLLY L/R | 跟随行走，保持关系 | 需要轨道，写进备注 |
| 摇 / 俯仰 | PAN / TILT | 揭示、连接两个信息 | 慢摇；快摇在大画幅上会糊且晕 |
| 升降 | CRANE UP/DOWN | 尺度转换 | 1.43 的高度让升降特别有效 |
| 车载 / 机载 | CAR MOUNT / AIRCRAFT MOUNT | 载具视点 | 硬固定在机身/车身上，这是诺兰的常规操作 |
| 旋转布景 | SET ROTATION | 失重、反转、梦境 | 实拍：转的是布景不是摄影机 |
| 变焦 | ZOOM | **基本不用** | 定焦球面镜为主 |

**运动的理由**要写进分镜备注：跟随谁？揭示什么？为什么现在动？答不出就用固定机位。

## 4. 场面调度

- **人动优先于机器动**。让演员穿过画面、进出前景，比推轨更有力
- **一镜内完成关系变化**：进门 → 走近 → 坐下，构图从远到近，不切
- **实用光源作为调度锚点**：人物走向灯、背对火、被探照灯扫过
- **群体作为纹理**：人群、士兵、科学家——用重复个体填充大画幅的面积

## 5. 剪辑与转场

| 转场 | 标记 | 用法 |
| --- | --- | --- |
| 直切 | CUT | 默认，占 90% |
| 匹配剪辑 | MATCH CUT | 形状/动作/构图相似的两格相接——跨时空的主力手法 |
| 交叉剪辑 | INTERCUT | 多条时间线并行推进，节奏各不相同 |
| 声音先入 | J-CUT | 下一场的声音先进来 |
| 画面先切 | L-CUT | 上一场的声音延续到下一场 |
| 淡入淡出 | FADE | 慎用，段落级分隔才用 |
| 白闪 / 曝光过度 | FLASH | 爆炸、记忆闯入 |

**画幅切换本身就是一种转场**。从 2.39 切到 1.43 的瞬间，画面上下"打开"，观众身体上能感觉到——把这个瞬间放在情绪转折点上。

### 轴线（180° 规则）

给每场戏画一张**俯视机位图**，标出动作轴线和各机位编号。跨轴要么不做，要么用中性镜（沿轴线拍）、运动镜（镜头连续越过）过渡，并在备注里写明为什么要跨。

追逐戏保持**统一银幕方向**：A 始终从左向右，B 始终从右向左，观众才不会迷路。

### 眼神匹配

正反打里，A 看向画右，B 就必须看向画左。1.43 画幅上人脸大，眼神方向的错误会非常刺眼。

### 光的银幕方向会随反打翻转

这是最容易写错的一条。**同一盏灯，在正打和反打里落在画面的相反一侧。**

主镜里窗在画右，转过来拍反打时，摄影机掉了个头，那扇窗就出现在**画左**。灯没动，动的是机器。

所以：

- 每个镜头的 `light` 字段都要写**相对画框**的方向（画左 / 画右 / 顶光 / 背光 / 正面），不能只写"窗光打在脸上"
- 写反打镜时，先在俯视机位图上确认摄影机站在轴线的哪一边，再决定光落在画面哪一侧
- 一组正反打里两个人的受光侧**本来就应该相反**——看到相反不要急着当成错误，先回机位图上核对

出图时这一条尤其要盯：图像模型对"光从画右来"的执行成功率很低，经常给你画左。发现方向不对，先确认是模型没执行，还是反打本来就该翻——两者的处理方式完全不同。

## 6. 节奏

- 镜头时长写进 `duration`（秒）。段落总时长 = 各镜时长之和，用它检查节奏设计
- 紧张段落：镜头变短，但**不要碎到看不清**。大画幅需要眼睛扫视的时间，**信息密集的镜头**（全景、多人调度、复杂环境）一格至少 1.5 秒
- 这条下限**不适用于插入镜**。锁扣、踏板、按钮这类单一主体的微距特写信息量极小，0.6–1.2 秒就读完了，启动流程一类的快切蒙太奇正是靠这个长度出节奏。判断标准是"画面里有几件事要看"，不是"画幅有多大"
- 大远景、尺度镜：给足 4–8 秒，让观众看
- **静默 + 长镜**紧接**短切爆发**，是最有效的对比结构
- 让声音决定切点：机械节拍、秒针、心跳可以直接当剪辑节拍器

## 7. 每一格必须回答的问题

画完一格，逐条自问：

1. 这是什么画幅？为什么是它？
2. 景别和焦距分别是什么？
3. 光从哪里来？
4. 摄影机动不动？为什么？
5. 主体在画面的哪个位置？上下空间在做什么？
6. 这一格接在哪一格后面？用什么转场？
7. 声音是什么？
8. 这个镜头能实拍吗？怎么拍？

八个问题答不全，这一格就还没画完。
