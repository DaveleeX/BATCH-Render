# 段落模板：诺兰式结构

分镜不是一格一格攒出来的，是**先有段落结构，再往里填镜头**。这里给七个可直接套用的结构，每个都带镜头配比和节奏表。

用法：选一个模板 → 按它的 beat 表列 shot list → 再逐格出图。

---

## 1. 多线交叉剪辑（不同时间尺度）

**用途**：让三条速度不同的线在同一个高潮点汇合。《敦刻尔克》的一周 / 一天 / 一小时是极端形态。

**结构**

| 线 | 时间跨度 | 节奏 | 画幅建议 |
| --- | --- | --- | --- |
| A 线 | 最长（周/天） | 最慢，镜头长 | 1.43（尺度、环境） |
| B 线 | 中等（小时） | 中速 | 1.43 / 2.20 混用 |
| C 线 | 最短（分钟） | 最快，镜头短 | 1.43（贴身） |

**做法**

- 三条线在**银幕时间上等长**，但覆盖的故事时间差几个数量级。观众会自动接受
- 切换点放在**动作未完成时**——上升的悬念被打断，转到另一条线
- 用**共享元素**做缝合：同一架飞机、同一个声音、同一片天空，让三条线在视觉上属于同一个世界
- 越接近高潮，切换越频繁，三条线的时间刻度逐渐对齐

**镜头配比（一个 5 分钟段落，约 55–70 格）**
A 线 20 格（平均 6 秒）/ B 线 22 格（平均 4 秒）/ C 线 25 格（平均 2.5 秒）

**常见错误**：三条线节奏一样快 → 交叉失去意义，变成单纯的场景切换。

## 2. 倒计时（滴答钟）

**用途**：给一段没有反派的戏制造压力。

**结构**

1. **立规则**（3–5 格）：明确显示时限从哪来——仪表、引擎、燃料表、潮水、日程表。给一个可读的数字或可见的物理量
2. **周期性提醒**（每 30–60 秒银幕时间插 1 格）：插入镜（micro-macro）回到那个数字/量
3. **递减间隔**：提醒的间隔越来越短，镜头也越来越短
4. **最后一次提醒后不再提醒**：临界点前拿掉钟，观众自己数
5. **解决或失败**：一格定格，然后立刻切走

**声音**：机械节拍与画面切点对齐。到后段让节拍加速或**突然消失**。

**镜头配比**：主线镜头 ×N + 倒计时插入镜 ×6–8。插入镜要用同一机位、同一构图，只有数字变——重复本身就是压力。

**常见错误**：倒计时插入镜每次换机位换构图 → 观众读不出"又近了一步"。

## 3. 静默 — 爆发

**用途**：单个决定性事件（爆炸、撞击、揭示）。让事件之前的空白比事件本身更响。

**Beat 表**

| 阶段 | 格数 | 平均时长 | 内容 |
| --- | --- | --- | --- |
| 准备 | 6–10 | 3–5s | 流程化动作：戴护目镜、涂防晒、检查开关。全部固定机位 |
| 等待 | 4–6 | 5–8s | 越来越长的镜头，越来越少的动作。脸、地平线、空。**声音逐渐抽空** |
| 绝对静默 | 1–2 | 4–6s | 完全无声。通常是一张脸或一片空景。不要动 |
| 事件（无声） | 3–6 | 1–3s | 光先到：过曝、白闪、被照亮的脸。**依然无声** |
| 延迟的声音 | 1 | 2–4s | 冲击波和轰鸣到达。这一格可以是全片最大的画面 |
| 余波 | 4–8 | 2–6s | 尘、静止、耳鸣式的低频，人物反应 |

**关键**：光和声音**分离**。真实物理如此（光快声慢），戏剧效果也最强。

**画幅**：全程 1.43，事件格用最大的画幅面积。

**常见错误**：爆炸和声音同步 → 变成普通动作片。

## 4. 听证会 / 审讯（对白正反打）

**用途**：靠语言而不是动作制造压迫。

**空间设计**

- 小房间、低天花板、单一光源（窗或吊灯）
- 被审者位置**低于**审问者，或被包围在人群中央
- 对称构图正对被审者；审问方用略偏轴的角度

**镜头组**

| 镜头 | 用途 |
| --- | --- |
| 主镜（MS/WS，对称） | 建立空间与人数关系，每隔一段回来一次 |
| 被审者 MCU→CU→ECU | 随压力递进逐渐推近。**景别本身就是压力曲线** |
| 审问者 MCU（略偏轴） | 保持稍远，不给同等的亲密度 |
| 旁观者插入镜 | 反应、交换的眼神、笔尖 |
| 手部/纸面插入镜（micro-macro） | 文件、颤抖的手、烟灰 |

**画幅**：同期声对白 → 2.20:1。当情绪突破、进入主观回忆或崩溃时**切到 1.43**——画幅"打开"的瞬间就是情绪爆发点。

**节奏**：初期镜头长（6–10s），交锋后逐渐缩短（2–3s），最紧张处只切脸。

**常见错误**：从头到尾同一个景别切来切去 → 没有压力曲线。

## 5. 物理反转 / 失重

**用途**：旋转走廊、零重力、时间倒流——认知失调型奇观。

**实拍原则**：**转的是布景，不是摄影机**。摄影机相对布景固定，演员在旋转的空间里表演。分镜必须画得让美术组看懂这一点。

**镜头组织**

1. **建立正常**（2–3 格）：先给一个绝对正常的空间基准
2. **打破**（1 格）：第一个不对劲的细节——一件东西朝错误方向落下
3. **完全失序**（6–12 格）：人在墙上走、水平线持续旋转。机位相对布景固定，让世界转
4. **重新锚定**（2 格）：回到一个可辨认的方向，让观众重新站稳

**分镜画法**：在每一格标注**重力方向箭头**（相对画框），并在备注写明"布景旋转 X°，摄影机固定于布景"。

**时间反转的额外规则**：倒放的动作要在分镜上标 `REVERSE`，并画出正放时的动作起止——演员和特技要按倒过来的动作排练。

## 6. 大尺度实拍奇观

**用途**：IMAX 存在的理由。飞行、坠毁、洪水、天体。

**结构**：不要一上来就给最大的。按**三级递进**：

1. **人的视角**（2–4 格）：从地面/舱内看，有人在画面里做尺度参照
2. **过渡尺度**（2–3 格）：拉开，人变小，环境成为主体
3. **绝对尺度**（1–2 格）：最大的一格。可以完全没有人。给足时长（5–8 秒）

然后**立刻回到脸**——1 格反应镜。奇观没有人的反应就只是屏保。

**注意**

- 大画幅段落每格给足停留时间，观众需要时间扫视
- 每格备注写实拍方案：实景？真炸？微缩模型？机载摄影机硬固定？
- 至少保留一个**人在画面里**的尺度参照物

---

## 7. 移动中的说明性对白

**用途**：塞进大量设定信息而不让观众睡着。

**做法**

- 人物**边走边说**，穿过一个正在运转的空间（工地、走廊、实验室、甲板）
- 环境本身在演示信息——嘴上说的东西，背景里正在发生
- 摄影机后退跟拍或侧移跟拍，构图随行走自然变化
- 关键信息点上切一个插入镜（图纸、装置、名单）
- **不要**用固定机位两人对坐说五分钟

**镜头配比**：跟拍长镜 2–3 个（每个 15–30 秒，分成多格画）+ 插入镜 3–5 格 + 反应镜 2 格。

**画幅**：同期声 → 2.20:1。

---

## 组合成整片

一部片的骨架通常是这些模板的交替，交替的**依据是情绪曲线**，不是随机：

```
7 说明（信息密度高、画幅窄）
  → 4 审讯（压力上升、景别收紧）
    → 2 倒计时（引入时限）
      → 1 交叉剪辑（多线并进、加速）
        → 3 静默—爆发（顶点）
          → 6 奇观（余波尺度）
            → 4 审讯（回到人、回到后果）
```

写段落表时，把这条链画出来，并标出每一段的画幅——**画幅的变化曲线应该和情绪曲线吻合**。
