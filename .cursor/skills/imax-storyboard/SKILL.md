# IMAX 电影分镜（Nolan 大画幅质感）

把一段文字（剧本、梗概、一句创意）转成**可以直接进组用的分镜**：格式策略 → 段落设计 → 分镜表 → 逐格画面 → 装订成册 → 可选 Blender previz。

标准不是"看起来像电影海报"，而是**这一格能不能拍**：画幅、镜头、光源、机位、时长、声音、与前后镜的剪辑关系，每一项都要成立。

## 工作流

按顺序做。**不要跳过第 1、3 步直接出图**——没有格式策略和 shot list 的图只是插画，不是分镜。

### 1. 立格式策略（Format Policy）

先回答三个问题，写进 `project.format_policy`：

- **主画幅**：这个故事的"大"在哪？人物内心（1.43 大特写）还是环境压迫（1.43 全景）？IMAX 的 1.43:1 接近方形，它换来的是**竖向信息**——天空、天花板、纵深地面，不是横向全景。
- **副画幅**：哪些戏必须让位？同期声对白戏在真实拍摄里会因 IMAX 机身噪音改用 5-perf 65mm（2.20:1）或 35mm（2.39:1）。分镜里保留这个切换，是给剪辑和后期一个明确的叙事分层信号。
- **画幅切换的意义**：诺兰的画幅跳变不是随机的，它标记**叙事层级**（客观/主观、现实/记忆、彩色/黑白）。给每次切换写一句理由，写不出理由就不要切。

真实工作方式是"**按 2.39 构图，保护 2.39 画框之外的部分**"：主体信息压在中央的 2.39 区域内，而 1.43 画幅上下多出来的天地照样要拍好、要有内容——那是 IMAX 独有的沉浸感余量。分镜上用保护框把这条界线标出来。

### 2. 拆段落，定节奏

用 [段落模板](references/sequence-playbooks.md) 选结构（交叉剪辑 / 倒计时 / 静默—爆发 / 听证会正反打 / 物理反转）。

输出一张**段落表**：段落名、时间线归属、画幅、镜头数、预估时长、情绪曲线、与其他段落的交叉点。先有段落表，再有分镜。

### 3. 写 shot list → `shots.json`

每个镜头至少写全：编号、场景条（slug）、画幅、景别、镜头焦距、运动、动作、光、声音、时长、与下一镜的转场。字段定义见 [交付规范](references/deliverables.md)。

镜头编号用 `12A / 12B / 12C`（同一场的不同机位/覆盖），不要用连续自然数——加镜头时不用重排。

### 4. 出风格基准板（Style Plate）

**先只画一格**，用它锁定整册的画风、色调、线条、颗粒。经用户确认后，把这一格作为后续每一格的参考图（`reference_image_paths`）传入，保证全册一致。

跳过这一步的直接后果是：60 格里有 6 种画风。

### 5. 逐格出图

用 [出图配方](references/image-prompt-recipes.md) 的模板拼提示词，顺序固定：
`画风 → 画幅 → 景别+焦距 → 主体与动作 → 机位与运动 → 光源与氛围 → 色彩与胶片 → 构图指令 → 排除项`

画幅映射（图像模型只给固定比例，装订时再裁到真实画幅）：

| 目标画幅 | 生成比例 | 装订时的处理 |
| --- | --- | --- |
| 1.43:1（IMAX 15/70） | `4:3` | 上下各裁约 3.4% |
| 1.90:1（IMAX 数字） | `16:9` | 上下各裁约 3.2% |
| 2.20:1（5-perf 65mm） | `16:9` | 上下各裁约 9.6% |
| 2.39:1（35mm 变形宽银幕） | `16:9` | 上下各裁约 12.8% |

裁切由 `build_storyboard.py` 用 CSS `object-fit: cover` 自动完成，不需要手工裁图。

把图存到 `panels/<镜头号>.jpg`，并写回 `shots.json` 的 `image` 字段。未出图的镜头不要写 `image`，装订时会渲染成"待绘制"占位框。

### 6. 装订

```bash
python3 .cursor/skills/imax-storyboard/scripts/build_storyboard.py shots.json -o storyboard.html
```

生成单文件 HTML（无第三方依赖），含封面、分镜格页、shot list 表；浏览器打印即 PDF。缺图的镜头渲染成占位框，方便边写边看。

可选：在 Blender 里核对真实视野与景深——

```bash
blender -b scene.blend -P .cursor/skills/imax-storyboard/scripts/imax_previz.py -- --shots shots.json
```

按 IMAX 15/70 真实感光面（70.41 × 52.63 mm）建摄像机，焦距、画幅、时长全部对应 shot list。这是唯一能验证"50mm 到底有多广"的方法。

## 硬规则

违反这些，质感就散了：

1. **球面镜，不用变形宽银幕**。诺兰的大画幅片全部球面拍摄——玻璃更少、折射更少、画面更纯。不要写 anamorphic flare、蓝色横向光斑那一套，那是 J.J. Abrams，不是诺兰。
2. **焦距只在 50mm 和 80mm 之间选**（IMAX 画幅上）。更长会"压扁成平面图形"，更广会"鱼缸化，边缘掉得太快"。特殊需求才上潜望镜头/微距。换算成全画幅约等于 **26mm 和 41mm**——所以 IMAX 的"特写"其实是用中焦贴近拍的，人物周围留着大量环境。
3. **24fps，不要升格滥用**。紧张感来自实时，不来自慢镜。
4. **光要有来源**。窗、灯、火、爆炸、仪表盘——每一格都要能指出光是从哪儿来的。不要"电影感打光"这种空话。
5. **实拍优先**。写在分镜备注里：这个效果怎么实拍？真实布景、真实爆炸、真实旋转走廊。数字合成是兜底，不是首选。
6. **不要黑得没细节**。大画幅胶片的阴影是有层次的，不是压死的纯黑。
7. **不画不能拍的镜头**。物理上不可能的机位、不存在的光源、演员做不到的动作——一律重画。

## 自检清单

交付前逐条过：

- [ ] 每次画幅切换都有一句叙事理由
- [ ] 每格标了焦距，且都在 IMAX 的 50/80 甜区（或写明了为什么例外）
- [ ] 每格能指出光源
- [ ] 全册画风一致（用了同一张 style plate 作参考）
- [ ] 轴线（180° 规则）没有无意破坏；故意破坏的地方写了理由
- [ ] 每格有时长，段落总时长与节奏设计吻合
- [ ] 关键动作镜有前后衔接镜（进入镜 / 反应镜），不是孤立的漂亮画面
- [ ] 声音提示写在了该写的地方（Shepard tone 式持续升调、静默、低频）
- [ ] 1.43 的格子里，上下多出来的空间在做事（天空、地面、天花板、纵深），不是白留
- [ ] `shots.json` 能跑通 `build_storyboard.py`
